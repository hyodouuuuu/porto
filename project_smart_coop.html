Internet of Things & Dashboard

Smart Coop

Sistem otomasi dan pemantauan peternakan ayam berbasis mikrokontroler untuk optimalisasi produktivitas dan kesehatan hewan ternak.

Role

IoT Engineer & Full-Stack Developer

Tech Stack

ESP32, API, Web Dashboard, MQTT/HTTP

Core Deliverables

Real-time Telemetry, Automated Fans, detection chicken

The Problem

Monitoring kondisi kandang yang belum optimal.

Pada peternakan ayam konvensional, pemantauan suhu, kelembapan, serta kondisi lingkungan kandang masih banyak dilakukan secara manual. Akibatnya, perubahan kondisi kandang sering terlambat diketahui sehingga dapat memengaruhi kesehatan dan pertumbuhan ayam. Selain itu, proses pemantauan populasi serta pengelolaan kandang membutuhkan waktu dan tenaga lebih karena belum terintegrasi dalam satu sistem yang dapat diakses secara real-time.

The Solution

Otomasi kendali hardware & pemantauan data terpusat.

Solusi yang diimplementasikan adalah ekosistem pintar yang menghubungkan node sensor fisik di dalam kandang langsung ke sebuah web dashboard melalui arsitektur IoT terintegrasi dengan tiga fungsi utama:

AI-Based Chicken Detection

Memanfaatkan model YOLO untuk mendeteksi ayam secara otomatis melalui kamera untuk membuka pintu.

Real-time Environmental Monitoring

Menggunakan sensor untuk membaca suhu sekunder serta kelembapan udara kandang secara kontinu tiap detik.

Automated Microclimate Control

Sistem aktuator otomatis yang akan menyalakan lampu jika suhu terlalu dingin.

Livestock Calculation Dashboard

Visualisasi data pertumbuhan, kalkulasi total populasi, serta grafik analitik kondisi kandang dalam satu antarmuka web.

Hardware Health Monitoring

Memantau status perangkat secara real-time untuk memastikan sensor, kamera, dan mikrokontroler beroperasi dengan baik.

Tools & Technologies

YOLO Object Detection Chicken Detection & Counting
